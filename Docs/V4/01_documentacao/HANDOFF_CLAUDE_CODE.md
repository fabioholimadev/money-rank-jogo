## 10. Imposto e fiscalização — fluxo executável
Ao fechar ano, pagar salário de todos ativos primeiro. Para cada jogador em ordem, `T=ceil(salary*rate/100)`. Casas: IPTU=50*imoveis, IPVA=40 se ativo, ISS=30, ICMS=40. Pagar T ao cofre e aplicar +1 Cidadania base se parâmetro habilitado. Se sem recursos após resgate, aplicar +3 Dívidas, registrar principal T como inadimplente, sem moeda. Sonegar só se conseguiria pagar T: feliz -> record principal T sonegado; triste -> cobrar 2T e +1 Cortisol, se não puder pagar o dobro mesmo após resgate, registrar autuado outstanding=2T e +3 Dívidas (sem cobrança parcial por default). No próximo gatilho fiscal, lançar uma moeda para conjunto de pendências antigas: feliz mantém; triste calcular somatório dos valores (2*principal dos não autuados, outstanding dos autuados), +1 Cortisol base uma vez por fiscalização, cobrar integralmente se puder, regularizar os registros pagos. Caso não possa, registrar todos como autuados por valor calculado, +3 Dívidas base, sem aplicar dobra novamente. Sem juros, sem expiração, sem segunda punição retroativa automática. Pendências públicas no online, privadas do mestre local; o resultado do evento pode ser apresentado sem exibir registro privado.
