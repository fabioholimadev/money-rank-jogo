# Pacote visual V4
- tabuleiro_mapa.png: mapa top-down numerado, orientação do layout anterior; a foto física foi girada 90° no enquadramento. Não é gabarito de corte ou impressão em escala.
- inventario_casas.png: legenda visual completa dos 36 IDs, nomes e categorias.
- icones/: 36 tiles PNG (256×256); H19, H25, H32 e H34 têm SVG original editável adicional. H25 ISS substitui IOF, H32 ICMS substitui IR, H34 Investimento Livre substitui aplicação financeira, H19 substitui o antigo Banco. Os outros tiles foram recortados das faixas e layout fornecidos; são referência raster, não vetores nativos nem aumento real de resolução. Para arte de produção, use os originais vetoriais do projeto quando existirem.
- cartas/: PNG 800×1120 por opção de casa, carta de progressão e evento do sistema. Valores fixos são pontos-base; calcular os efeitos reais na interface. Cartas de sistema usam texto; opções com parâmetros dinâmicos dependem do motor. PNGs são referência visual e podem servir de mockup; UI deve renderizar texto dinamicamente a partir do CSV/JSON.
- A IA desenvolvedora deve pesquisar modelos 3D licenciados, capivaras melhores, peões de xadrez e modelos do hospital/cofre e criar background/UI. Este pacote não contém modelos 3D obtidos na internet. As fontes tipográficas foram usadas para renderização, não distribuídas. Não reproduza ativos de terceiros sem verificar licença; os recortes se originam da arte fornecida pelo usuário.
